# Working on OSM Content

This repository owns the optional Content method and adaptable template source.
It is outside the OSM plugin. Preserve the boundary and existing human workflows.

Read README.md, then only the relevant contract/template. Keep business-specific
configuration, private examples, media, credentials and owner routes out of Git.
Do not copy the private Data & Context home into this repository.

Templates are starting instructions, not installed personal skills. Preserve
source versions and provenance. Version any later instruction changes separately
from this unchanged initial import. An installation, release, schedule or outward
publication requires its actual authority; a method does not grant it.

Check changed relative links, source inventory and affected adoption callers.
Review whether instructions support a real task, rather than testing only their
wording. Keep documentation synchronized with actual source and evidence. Do not
claim native adoption, editor qualification or complete style calibration from
static checks. Coordinate OSM core changes with its existing owner; no parallel
rewrite of OSM or reactivation of the archived content system.
