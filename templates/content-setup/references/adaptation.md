# Adopting this template

This is starting material for an owner's personal skill, not a universal installed Content plugin. The public Content extension supplies the setup/configuration method. The actual owner's selected Notion Data & Context entry supplies routes, policy and relevant Knowledge.

When adopting or revising, discover the available skill-management procedure (for example the actually installed OSM Manage Skills method). Query existing personal methods for overlap and preserve useful originals/references. Choose the useful responsibilities, discriminating names/descriptions and actual input/output routes. Save the adapted method through the selected personal Skills mechanism and reference one short owner configuration in Knowledge. Do not copy a complete private strategy into every skill or substitute unreleased OSM identifiers.

Configuration resolves the actual Content collection/data-source, field meanings, goal/audience/voice references, editorial originals, selected channels, source/media/editor routes, human participation, delivery policy and any real native automation IDs. Null/unknown is not an operational default. Do not invent accounts, expand grants or start timers to make a template look complete.

At ordinary use, load only the relevant accepted configuration and task material; do not redo onboarding. Preserve selected source/version/hash and local adaptations. Record the actual personal-Skills location/ID, source template package/hash and observed discovery/invocation evidence. Keep key convention and integration triggers/safe states in the accepted configuration so later status/edition writes follow the same rules. A copied bundle or saved page is not proof of native installation, enablement, discovery or use. Exercise one representative authorized task and record its real limits. A replay must not duplicate data or delivery.

The same adopted method may be manually invoked or used by a separately selected schedule. Template adoption does not authorize public posts, mail sends, subscriber changes, new accounts or new connections. Existing standing authority is reused where applicable.
