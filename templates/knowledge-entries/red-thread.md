# Red thread · optional coherence prompts

Reuse existing vision, positioning, voice/style and operating-policy records. This form is useful only when coherence guidance is missing and the owner wants it. Do not create a parallel strategy or make a separate red-thread page compulsory.

- Themes or connecting idea: link existing vision/positioning when sufficient.
- Recognizable expression, if chosen: link voice/style and selected formats.
- Publication boundaries: link the existing privacy/operating policy. Ask only a missing boundary that affects the piece; prescribe no personal categories.
- Inspiration: permitted Source references and the technique selected for use.
- Useful coherence check: does the piece support the selected vision and channel goal, using the owner's actual expression and policy?

Keep facts at their existing owners. Formatting, disclosure and channel choices are owner decisions. Do not infer a common signature or raw-formatting default.
