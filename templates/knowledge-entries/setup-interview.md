# Setup prompts · ask only what matters

Read the selected plugin binding, relevant base records and existing Skills first. Reuse supported answers and useful workflows. This is a prompt bank, not a mandatory interview, fixed page list or a requirement to complete every field before useful work.

Resolve one blocking choice at a time. Write a supported answer once, on its existing owner; use links elsewhere. Add a topic only when the task needs it. A missing optional cadence or red thread does not block a draft.

| Gap that affects this task | Prompt and owning record |
| --- | --- |
| Direction | What should this piece/channel contribute? Reuse profile/soul, brand, priorities and vision in Knowledge |
| Reader and offer | Who should it help, and what offer matters if any? Reuse audience, positioning and offers |
| Voice evidence | Which existing writing or accepted examples are relevant? Follow [writing voice](../../docs/writing-voice.md); retain partial calibration honestly on the existing voice/style record |
| Channel assembly | What goal, language, format and media treatment has the owner chosen? Reuse channel strategy/format and Content templates |
| Policy | Which existing operating, privacy and review rules apply? Resolve only gaps affecting this piece |
| Planning, if wanted | Is a rhythm or on-demand plan useful? Optional horizon, capacity and category choices belong with [cadence](cadence.md) |
| Approval | Where will the owner mark approval of the final version/destinations? Reuse the review route; second-model review is optional |

Record only useful unresolved choices and their effects in existing configuration. Do not copy answers into an interview archive or create empty compulsory pages. Exercise the selected channel method on a bounded draft, run the gate, and report actual work separately from structural readiness or native skill discovery.
