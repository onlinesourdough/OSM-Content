# Content learning

Template edition 2026-11-05.1. Use the owner’s actual Content configuration and routes. Read [adoption](references/adaptation.md) when tailoring this into a personal skill; normal use loads only the selected configuration and relevant material. This template is not an installed or enabled method.

Read the actual edition/delivery and the primary goal revision it served and any selected secondary goal. Identify the chosen outcome before collecting metrics. Qualified enquiries, customers, audience growth, programme milestones and reader learning need different evidence; do not substitute a convenient platform number for the owner's purpose.

Gather a bounded observation from the configured sources or the owner's account of real responses. Record source, observation date/window, edition/version, relevant audience/roles, actual signals, effort, uncertainty and missing data. Unknown is not zero. Do not activate a new account/analytics source or retain unnecessary personal data just to fill the review.

Separate attention, relevant comments, enquiries, qualified opportunities and sales. A comment is not an attributable sale. People outside the ideal customer profile may refer or influence buyers; some outside-audience engagement does not prove failure. Compare sufficiently similar work and acknowledge distribution, topic, packaging and timing confounders.

Return one useful decision: keep, improve, test another approach or stop. State what supports it and propose one bounded next experiment. Small samples support hypotheses, not a proven causal rule. Consider sustainable effort, creative satisfaction and editorial fit as well as commercial evidence.

Keep concrete observations with the Content item/edition. A supported reusable conclusion can update its owning configuration in Knowledge under the actual authority; generic skill changes are deliberate revisions. Preserve human taste and chosen goals rather than silently redefining them around the latest popular post.

This step can be manual, assisted or a configured recurring review. Use a simple observation section before adding a dashboard or measurements store. A no-change review should not create duplicate lessons or pointless notifications. Daily OSM context upkeep maintains the selected data/context; it does not replace this editorial judgement or automatically start the next production.
