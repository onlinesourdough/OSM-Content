# Turn references into useful creative guidance

Use this when someone shares a creator, post, video, sound or visual treatment
they want to learn from. A reference can remain a saved source, inform one piece,
or support a reusable treatment. Keep those choices distinct.

## Capture what makes the example useful

Find the existing Source by its original URL or stable media ID before creating
one. Preserve the creator, original location and date when known. Record the
owner's reason for saving it separately from the agent's interpretation. A brief
note such as "the camera moves into the corner while the window stays readable"
is more useful than "nice editing".

Keep at least one concrete line per link explaining what was worth saving: the
cuts, music, text reveal, composition or another specific choice. For a long
video, add the relevant timestamp or range. If the reason is not yet known,
mark it as unconfirmed rather than inventing a preference. Preserve this note
with the link so the library remains useful months later.

Inspect the actual example. For video or audio, keep the relevant time range and
what was observed: framing, pacing, typography, transitions, drawn graphics,
sound cues or music. State what could not be inspected. A thumbnail does not
establish motion, and a transcript does not establish editing or sound.

Use the existing Source body and searchable metadata rather than requiring new
databases or a folder tree. A source may have several useful roles. Keep media
and editor files in their selected storage with an access route and backup
responsibility. A saved link is not a media backup or permission to reuse the
creator's footage, music or identity.

## Make the learning retrievable

| Where | What belongs there |
| --- | --- |
| Source | Original attribution, why saved, observed details and time ranges |
| Owner configuration | Selected brand, channel/language choices and accepted creative preferences |
| Existing style guide or treatment reference | A reusable explanation of how to apply the selected technique in this owner's work, linked back to its evidence |
| Personal skill | Changed working steps when the learning actually changes how the task should be performed |
| Production or Edition | Which references were selected, what was tried, the result and the owner's feedback |

When the owner asks to develop a style or update a method, translate the useful
technique into their own brand and purpose. Update the relevant existing guide,
recipe or personal method under its normal authority; preserve rejected examples
as rejected. A new reference alone is not an accepted preference or a reason to
rewrite a skill. Keep candidate treatments labelled until reviewed.

Separate presentation inspiration from the author's voice. Borrowing a way to
explain a concept does not make the creator's experience the owner's experience.
Music, screenshots, logos and text treatments follow the same evidence and
attribution rules as animation.

## Use it in the next piece

Retrieve a small set of references for the actual purpose, channel, language and
available material. Link the selected Sources from the production and briefly
name what will be used or adapted. Apply the owner's current style rather than
imitating a whole creator. Adapt editions independently for their readers.

After review, keep the accepted or rejected result on that production. Feed a
lasting preference back into its existing owner record. Revisit a reusable
treatment when new evidence changes it. There is no implied scraping schedule,
new installation or automatic publication.

For a bounded check, capture one reference, follow it into one draft, and repeat
the lookup. The source identity should be reused, the draft should name the
specific technique, and any method change should be traceable to the owner and
evidence. Static checks alone do not prove the resulting video has the desired
look or sound.
