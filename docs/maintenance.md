# Source and readable documentation

This repository owns shared OSM Content method and template development from
9 November 2026. The initial template import is unchanged v0.10.0 / edition
2026-11-05.1; each template's SOURCE.json describes its historical frozen packet.
The original public Notion templates and their downloadable packets are retained.

Notion provides the human guide under Onlinesourdough Method → Content. Link this
repository there and state which edition/revision a reference describes. Do not
publish private configuration, source examples, customer material or owner Skills.

When an accepted method/template change is delivered:

1. Review and validate the affected source, links and actual adoption contract.
2. Record the source commit and any new template version without relabeling old packets.
3. Reconcile affected Notion explanations, template references/downloads and marker.
4. Verify the actual saved/public result before marking that projection current.
5. Retain partial progress and reconcile unknown writes instead of creating duplicates.

An automated Notion publisher is not configured in this initial repository. Track
that separately; a maintenance document is not evidence of a working CI/CD sync.
Reuse the existing documentation-maintenance ownership and invocation, not a new
daily writer. OSM package releases and Content revisions are independent.
